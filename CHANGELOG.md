# Changelog

## [1.0.0]

### Initial version

- Desktop and mobile interfaces with a masonry gallery, full-screen viewing and image comparison.
- Krea2 Identity Edit, Qwen Image Edit 2511 and MiniMax H3 workflows, each with up to ten optional LoRA slots.
- Flux enhanced upscaling with configurable model files and consistency LoRA.
- Image cropping, generation settings, task progress and cancellation.
- Collections, parameter reuse, sharing and a recycle bin.
- Account invitations, user limits, shared queues and storage diagnostics.
- Windows setup scripts, configurable model paths and pre-generation dependency checks.
- Unit tests, browser tests and Chinese and English documentation.
- GPL-3.0-only licensing for project-authored code.
