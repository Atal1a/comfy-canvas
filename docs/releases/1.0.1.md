# Comfy Canvas 1.0.1

补回 Krea Turbo 文生图。输入提示词即可生成图片，不需要参考图；支持画幅、生成数量、Seed 和最多十个可选 LoRA。

- 保留官方 Turbo 模型的 8 步、CFG 1、Euler / simple 默认采样设置。
- 默认不加载 LoRA，负面提示词为空。
- 新增文生图模型配置及缺失文件检查，兼容已有 Krea Identity 模型配置。
- 首页增加文生图入口，中英文介绍分别说明图片生成、图片编辑和视频生成。
- 更新双端截图和演示视频，加入真实文生图结果、LoRA 说明与参数设置。

## 从 1.0.0 升级

更新应用文件，保留自己的 `config.toml` 和 `data` 目录，再运行 `scripts/bootstrap.ps1`。

如果 `config.toml` 中设置了 `[features].workflows`，在列表中加入 `"krea-turbo"`。文生图默认沿用 `[models.krea_identity]` 中的主模型、文本编码器和 VAE；也可以使用 `[models.krea_turbo]` 单独配置这三个文件。文生图不需要 Identity Edit LoRA。
