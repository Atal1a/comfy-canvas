# Comfy Canvas 1.0.0

Comfy Canvas 的首个版本：在 Windows 电脑上运行，把 ComfyUI 工作流放进适合桌面和手机使用的创作界面。

## 创作与浏览

- Krea 图片编辑、Qwen 图片编辑、MiniMax H3 视频生成，以及 Flux 高清放大。
- 参考图上传和裁切、LoRA 说明与权重设置、生成进度和任务取消。
- 瀑布流、全屏查看、原图对比、参数复用和继续编辑。
- 收藏、消息分享和回收站；手机端支持一、二、三列瀑布流切换。

## 两种使用方式

自己在电脑上创作，或将这台电脑作为局域网服务器。其他人通过浏览器注册账号，共用服务器的生成队列；管理员管理邀请、用户和存储。

## 安装

下载源码包，解压后按 [Windows 安装说明](../setup.md) 配置 ComfyUI、模型和应用。环境配置使用 `config.toml`，工作流节点见[依赖安装](../dependencies.md)。
