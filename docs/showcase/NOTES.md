# 展示素材说明

[项目首页](../../README.md) · [界面展示](README.md)

截图与操作短片使用 Comfy Canvas 的实际界面和演示数据。陶器静物、庭院日夜编辑为实际工作流输出；其他示例图片用于展示界面布局。

陶器静物使用 Cinematic Film、Fujifilm 和 Photography Style LoRA 生成，模型文件不随项目分发。

介绍视频与操作短片经过剪辑，使用预先完成的生成结果，不代表实际生成耗时。介绍视频的配乐由程序合成，未使用外部音乐或采样。

The screenshots and interaction clips use the actual Comfy Canvas interface with demonstration data. The ceramic still life and courtyard lighting edit are real workflow outputs; other sample images illustrate the interface layout.

The ceramic still life was generated with Cinematic Film, Fujifilm and Photography Style LoRAs. Model files are not distributed with the project.

The videos are edited and use results generated beforehand; they do not represent generation time. The intro music was synthesized programmatically without external music or samples.
