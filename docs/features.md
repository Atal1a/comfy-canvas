# 功能与工作流

[返回首页](../README.md) · [桌面展示](showcase/desktop/README.md) · [手机展示](showcase/mobile/README.md)

- 上传、预览和裁切图片，填写编辑要求，再调整生成参数。
- 查看排队和处理进度，取消任务，浏览结果。
- 在历史记录里筛选、排序、收藏图片，复用参数或继续编辑、放大。
- 删除的内容进入回收站，15 分钟内可恢复，逾期自动永久清理。
- 使用独立账号，通过消息分享结果；管理员管理用户、任务并查看运行诊断。
- 手机瀑布流支持 1／2／3 列双指切换；单张图片支持缩放和拖动。

## 工作流

| 工作流 | 用途 |
|---|---|
| Krea2 Identity Edit | 官方 Turbo 模型，单图编辑、身份重塑和双参考图 |
| Qwen Image Edit 2511 | 图片编辑，带 Lightning 加速 |
| MiniMax H3 | 文生视频、首帧图生视频和音频生成 |

每条主工作流最多可添加 10 个用户 LoRA。另有 Flux 高清放大；其一致性 LoRA 可以自行配置，文件缺失时跳过该加载器。

模型和工作流依赖需要自行配置，见[模型说明](models.md)和[依赖说明](dependencies.md)。
