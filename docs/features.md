## 图片生成

Krea Turbo 根据提示词直接生成图片，不需要上传参考图。

可设置画幅、生成数量和 Seed，从 LoRA 说明中选择模型并调整权重，最多使用十个可选 LoRA。默认不加载 LoRA，负面提示词为空。

## 图片编辑

上传、预览和裁切图片，用提示词描述要修改的内容。Krea Identity 支持图生图、人物身份重塑，以及场景与人物双参考图。生成后可以对比原图、复用参数继续编辑，或进行高清放大。

## 视频生成

MiniMax H3 支持文生视频、首帧图生视频和音频生成，可设置时长、画幅等参数，并在结果页播放视频。

## 任务与作品管理

- 查看排队和处理进度，取消任务，浏览结果。
- 在历史记录里筛选、排序、收藏图片，复用参数或继续编辑、放大。
- 删除的内容进入回收站，15 分钟内可恢复，逾期自动永久清理。
- 使用独立账号，通过消息分享结果；管理员管理用户、任务并查看运行诊断。
- 手机瀑布流支持 1／2／3 列双指切换；单张图片支持缩放和拖动。

## 工作流

| 工作流 | 用途 |
|---|---|
| Krea2 Turbo | 无需参考图的文生图，可选十槽 LoRA |
| Krea2 Identity Edit | 官方 Turbo 模型，图生图、单图编辑、身份重塑和双参考图生成 |
| Qwen Image Edit 2511 | 图片编辑，带 Lightning 加速 |
| MiniMax H3 | 文生视频、首帧图生视频和音频生成 |

每条主工作流最多可添加 10 个用户 LoRA。另有 Flux 高清放大；其一致性 LoRA 可以自行配置，文件缺失时跳过该加载器。

模型和工作流依赖需要自行配置，见[模型说明](models.md)和[依赖说明](dependencies.md)。
